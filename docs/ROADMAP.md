# Visão de longo prazo

O objetivo é que o Infosiga Analytics deixe de ser apenas um visualizador de planilhas e se torne uma plataforma completa para análise de acidentes de trânsito.

O sistema deverá ser capaz de:

- regularizar automaticamente logradouros;
- identificar inconsistências;
- gerar estatísticas;
- produzir dashboards;
- gerar mapas de calor;
- auxiliar pesquisadores e órgãos públicos na análise dos dados.
