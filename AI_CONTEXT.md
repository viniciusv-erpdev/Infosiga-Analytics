# Projeto Infosiga Analytics

## Objetivo

Sistema web para análise de acidentes do Infosiga.

## Tecnologias

- Python
- Django
- Pandas
- Bootstrap 5
- SQLite

## Estrutura

- Pasta raiz: infosiga-analytics
- App principal: analytics

## Funcionalidades atuais

- Upload de planilhas Excel do Infosiga.
- Tratamento de logradouros com Pandas.
- Correção automática de erros de digitação.
- Filtros por cidade e tipo de via.

## Funcionalidades futuras

- Dashboard.
- Heatmap.
- Ranking de vias.
- Estatísticas temporais.

## Diretrizes

- Não usar React.
- Não usar TypeScript.
- Utilizar Django Templates.
- Utilizar Bootstrap 5.
- Código simples e fácil de manter.
